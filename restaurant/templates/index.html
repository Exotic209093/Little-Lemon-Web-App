Welcome

Little Lemon is a charming neighbourhood bistro that serves simple food with a modern Mediterranean twist. This page is the static homepage served by Django to satisfy the capstone requirement.

Available APIs

  • GET /api/menu/ — list menu items (public)
  • POST /api/menu/ — create a menu item
  • GET/PUT/DELETE /api/menu/<id>/ — manage a single item
  • /api/booking/tables/ — CRUD bookings (auth required)
  • POST /auth/users/ — register a new user (Djoser)
  • POST /auth/token/login/ — obtain auth token (Djoser)
